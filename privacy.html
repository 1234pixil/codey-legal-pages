Privacy Policy

Codey (the "Bot") · Last updated 14 November 2026

HomeTerms of Service

This policy explains what information Codey handles, why, and your choices. We do not sell personal data and we do not use it for advertising.

1. Information Codey handles

Discord identifiers. User IDs, server (guild) IDs, channel IDs, role IDs and message IDs, so that settings and features work.

Information about how you use features. Depending on what a server enables, Codey stores things such as: XP, levels, coins and daily streaks; game and trivia statistics; Wordle history; collected critters; AFK status; reminders; giveaway entries; suggestions and tickets; polls; and server settings (for example welcome, level roles, role panels, starboard and permission choices).

Moderation records. Warnings, timeouts, kicks, bans, notes and cases, which can include the moderator, the reason entered and the time. Automod may remove messages that break the server's rules.

Message content. Codey needs to read messages to work (for example to answer when you talk to it, give XP, run automod or detect AFK mentions). Most messages are processed as they arrive and are not stored. Exceptions: messages addressed to Codey and its replies are sent to the AI model to produce an answer; messages that are copied by a server feature (starboard, suggestions, tickets, the action log) are stored in Discord by that feature; and short excerpts may be kept in moderation records.

Action log. If a server has it on, Codey posts every command used, questions asked of it and its replies, with the user and channel, into a channel chosen by the server (staff-only by default).

2. Why we use it

  • To provide the features you or your server ask for;
  • to keep servers safe (moderation, anti-spam, raid protection);
  • to prevent abuse of the Bot and fix problems.

3. Who else sees it

  • Discord delivers all messages and commands and stores the content Codey posts. Discord's own Privacy Policy applies.
  • AI provider. Text sent to Codey's chat is processed by an AI model run by the operator (Ollama, either on the operator's own computer or through Ollama's service). It is used only to produce the reply.
  • Hosting and storage. Bot data is kept by the operator on their own computer or on a database/hosting service (such as Supabase) used to run the Bot.
  • Wikipedia / Wikimedia. Codey downloads critter pictures; no personal data about you is sent.
  • Server staff. Moderation records and the action log are visible to the staff of the server they belong to.

We do not sell or rent personal data.

4. How long it is kept

Feature data is kept while the Bot is in your server so features keep working. Moderation records are kept until a server removes them or the Bot is removed. You can ask for your data to be deleted at any time (section 6). Backups may keep data for a short time afterwards.

5. Security

Secrets such as the bot token are kept out of the code and in private configuration. No system is perfectly secure, so we cannot guarantee absolute security.

6. Your choices and rights

  • Ask what Codey holds about you, ask for it to be corrected, or ask for it to be deleted, by contacting the Codey support server on Discord. Please include your Discord user ID.
  • Server owners can remove the Bot, turn off the action log (/actionlog off) and other features at any time.
  • Depending on where you live (for example the UK or EU), you may have further rights, such as to object to or restrict processing, or to complain to your data protection authority.

7. Children

Codey is for people who meet Discord's minimum age (13, or higher in some countries). We do not knowingly collect information from anyone younger. If you think a child's data is held, contact us and we will delete it.

8. Changes

We may update this policy. The date above shows the latest version.
